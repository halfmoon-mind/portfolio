# QR Maker

QR Maker is a web application that lets you generate QR codes quickly and easily without unnecessary ads.
You can generate QR codes for various types of data, such as URLs, text, contacts, and Wi-Fi information, and it also provides custom design options.

## Features

- Generate QR codes for various data types (URL, text, contacts, Wi-Fi, etc.)
- Custom design options (color, size, error correction level, etc.)
- Clean, ad-free interface
- Fast loading speed

## Tech Stack

- **React**: Frontend development
- **Vite**: Build tool
