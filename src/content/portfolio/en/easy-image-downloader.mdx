# Easy Image Downloader

Easy Image Downloader is a Chrome extension that lets you easily download images from Google Search and Namuwiki.
You can quickly save images from a web page with just a single right-click—no complicated steps required—and it also provides a feature to save images with an appropriately renamed filename.

It was developed using pure JavaScript and the Chrome Extension API, and it boasts lightweight, fast performance with no unnecessary ads or tracking code.

## Features

- One-click image download
- Filtering by image resolution and size
- Custom save path and filename settings

## Tech Stack

- **JavaScript**: Core feature development
- **Chrome Extension API**: Browser extension development
